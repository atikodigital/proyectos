# 📚 Instructivos de uso — Hash IA

Guías de uso de Hash IA (app de contabilidad con IA para pymes chilenas), pensadas para tres audiencias:

| Documento | Para quién | Qué contiene |
|---|---|---|
| [INSTRUCTIVO-CLIENTE.md](INSTRUCTIVO-CLIENTE.md) | **El cliente** (dueño y empleados de la pyme) | Cómo usar la app día a día: las 4 pantallas, Kaly por voz, VARAS, conciliación, reportes y la rutina recomendada. |
| [INSTRUCTIVO-ADMINISTRADOR.md](INSTRUCTIVO-ADMINISTRADOR.md) | **Tú** (Atiko, administrador) | Cómo instalar un cliente nuevo, usar el panel/dashboard del dueño, gestionar empleados y roles, y monitorear. |
| [CONOCIMIENTO-AGENTES.md](CONOCIMIENTO-AGENTES.md) | **Kaly y VARAS** (los agentes IA) | Conocimiento de uso listo para inyectar en sus prompts, para que guíen al cliente diciéndole **qué, cómo y cuándo** usar la app. |

> Estos documentos están escritos a partir del código real de la app (pantallas, prompts de Kaly/VARAS, panel web y endpoints), no de supuestos. Si una función está en desarrollo, se indica.
